# Constellation agent bootstrap

This file exists at the vault root so Codex and other agents can discover the
shared instructions automatically. The canonical instructions remain in
`x/AGENTS.md`.

Before responding or acting in this vault:

1. Read `x/AGENTS.md` completely and follow it.
2. Read `x/Priorities.md` and the newest entries in `x/Agent Log.md`.
3. Read the Family North Star when the task involves priorities or tradeoffs.
4. Check `.agents/skills/` for a matching shared workflow and use it when its
   description applies.

Do not treat attaching or opening this folder as a substitute for those reads.
